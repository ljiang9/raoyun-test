# 绕晕指数测试

2026 中秋国庆调休节奏问卷：7 道题测测你被"上5休1、上5休3、上3休7、上3休1"绕晕了几分。

## 梗来源声明

致敬 **2026-09-14 热搜第一**："上5休1、上5休3、上3休7、上3休1，网友：已绕晕"（2026 年中秋国庆调休节奏）。
本项目为善意玩梗的原创娱乐问卷，不针对任何个人或机构；调休数据依据 2026 年真实安排，星期已用 `date -d` 逐项核验。

## 玩法

- 交互模式：`python -m raoyun_test`，逐题回答"这天上不上班"（输入 上班/不上班）或数字。
- 自动演示：`python -m raoyun_test --auto --games 10 --seed 42`（AI 随机答题）。
- 评分：答对加权（权重合计 100），答错扣一半权重（非法输入按答错），总分钳在 0-100。
- 5 档绕晕等级：

| 分数 | 等级 | 评语 |
|---|---|---|
| 90-100 | 人间清醒 | 调休表倒背如流，建议去国务院办公厅兼职排班 |
| 70-89 | 轻微绕晕 | 偶尔把周六当周日，多喝热水就好 |
| 50-69 | 晕头转向 | 已经开始在日历上画圈圈了，全国人民陪你 |
| 30-49 | 彻底绕晕 | 上5休1、上5休3、上3休7、上3休1——分不清自己在哪一天 |
| 0-29 | 调休受害者 | 建议设为开机启动，每天默念三遍：今天上不上班 |

- 彩蛋第 7 题："下一次法定放假是 2027 年元旦，距离今天还有多少天"——动态计算。

## 诚实局限

- 调休数据写死为 2026 年安排，换年份需改代码；若官方安排有变，题目不会自动更新。
- 第 7 题按"今天"动态计算，跨年后（2027-01-01 之后）会算出负数，此时题目逻辑失效。
- AI 自动答题是纯随机模型，不代表真实人群分布。
- 纯文本界面，无图形/存档；Python 3.10+，纯标准库。
